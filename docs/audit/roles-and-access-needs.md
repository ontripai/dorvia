# Roles and Access Needs

| Role | Capabilities | Data Visibility |
|---|---|---|
| Visitor | Read public content, submit open forms | Public data only |
| Registered User | Save guides, track service status | Own profile & tickets |
| Business Owner | Manage 1+ provider profiles | Own provider & leads |
| Admin | Manage billing, lead routing | All |

*Note: /admin/comments requires strict Authentication, Authorization, Non-indexability, and CSRF mutation controls.*
