# First Days Checklist: Scenario Matrix

## Matrix of Scenarios

| Scenario ID            | Applicable Visas / Groups           | Medical Required | Fees Required | Timeline |
|-----------------------|-----------------------------------|------------------|---------------|----------|
| `student-arrival`       | Type D/SD, Uni Students           | Not Required     | 259 RON + 120 EUR | 30-45 Days |
| `employee-arrival`      | Type D/AM, Blue Card              | Required (Medicina Muncii) | 259 RON + 120 EUR | 30 Days |
| `family-arrival`        | Type D/VF, Spouses/Dependents     | Conditional (Non-contagious) | 259 RON + 120 EUR (Exempt for RO citizens) | 30-60 Days |
| `eu-citizen-arrival`    | EU/EEA/CH Citizens                | Not Required     | None | Same Day (CNP) |
| `short-stay-visitor`    | Type C, Tourists, Biz Visitors    | Not Required     | None | None (Max 90/180) |

## Document Matrix
- **student-arrival**: Passport (D/SD), Acceptance Letter, Housing (ANAF/Notary), Uni Medical Cert.
- **employee-arrival**: Passport (D/AM), Aviz de Muncă, REVISAL Contract, Housing (ANAF).
- **family-arrival**: Passport (D/VF), Sponsor ID, Birth/Marriage Cert, Proof of Housing/Funds.
- **eu-citizen-arrival**: National ID, Proof of Employment/Funds, Proof of Housing.
- **short-stay-visitor**: Passport (Type C), Travel Med Insurance.
