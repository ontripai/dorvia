# Driving License Estimated Cost Methodology

## Status: REMOVED

### Prior State
Previously, the guide contained a hardcoded estimate of "150-250 RON" for medical clinic certificates (Fișa Medicală) and "100-200 RON" for official translation and notary services. 

### Revision Reason
These numerical ranges were provided without a demonstrable sampling methodology, breaking the strict governance rules requiring either direct official citation or a defensible real-time methodology for private costs.

### Current Implementation
Private cost estimations have been completely **removed** from the fixed metrics. Instead, the guide explicitly advises applicants to contact authorized translation offices or accredited medical clinics directly to request a current quote. 

Only the standard, officially mandated 89 RON fee (for issuance and exchange) is retained, backed by DGPCI.
