# Operational Guide Standard

All operational guides must adhere to the typed `OperationalGuide` interface in `src/types/content.ts`.

## Principles
1. **Data-Driven**: Guides are structurally separated from UI components.
2. **Bilingual Parity**: English and Persian MUST contain the exact same substantive steps and facts.
3. **Scenario-Based**: Complex processes (like licenses or visas) must be broken down into discrete scenarios.
4. **No Commercial Bias**: Guides must not contain CTA elements to commercial services unless strictly legally required by the process.
