# Fact Check Workflow

1. Identify all claims (fees, timelines, steps).
2. Attempt to locate primary Romanian legislation or MAI/IGI directives.
3. If primary source is found, link it in `officialSources`.
4. If primary source cannot be found, use a verified secondary source (e.g., trusted law firm) and flag the fee/timeline as `isFixed: false` or `isGuaranteed: false`.
