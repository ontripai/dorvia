# تولید صدای رومانیایی برای درس‌ها

فایل‌های قدیمی Aoede/Puck به پخش برنمی‌گردند. پخش‌کننده تنها ورودی‌هایی را از `verified-audio.json` به کار می‌برد که متن آن‌ها دقیقاً با متن دکمهٔ درس یکسان باشد. سایر دکمه‌ها تا زمان تولید و تأیید فایل، همان صدای مرورگر را استفاده می‌کنند.

1. متن و `slug` یکتای هر واژه یا جمله را به `scripts/romanian-audio-catalog.json` اضافه کنید. برای صدای نام حرف و آوای حرف دو کلید جداگانه در رابط لازم است؛ صرفاً ثبت یک حرف منفرد در فهرست نمی‌تواند این دو را تشخیص دهد.
2. کلید و منطقهٔ منبع Speech را فقط در محیط محلی، خارج از مخزن، در `AZURE_SPEECH_KEY` و `AZURE_SPEECH_REGION` قرار دهید؛ سپس `npm run audio:azure` را اجرا کنید. `ffmpeg` باید نصب باشد. صدای پیش‌فرض `ro-RO-AlinaNeural` است؛ `AZURE_SPEECH_VOICE` را برای صدای رومانیایی دیگری تنظیم کنید.
3. فایل‌های `public/audio/romanian/verified/` را با متن، IPA و تلفظ مورد انتظار تطبیق دهید. کوتاه‌بودن یا ساخته‌شدن فایل تأیید تلفظ نیست. برای حروف، گروه‌حرف‌ها و وام‌واژه‌ها بازبینی انسانی لازم است.
4. تنها پس از تأیید، روی مورد مربوط در فهرست مقدار `"approved": true` بگذارید و دستور را دوباره اجرا کنید؛ آن‌گاه مسیر فایل در `src/content/romanian/verified-audio.json` ثبت می‌شود. تغییر متن یا صدا نیازمند بازتولید و بازبینی فایل قبلی است.

این ابزار فایل را یک‌بار تولید می‌کند و هنگام بازدید زبان‌آموز با Azure تماس نمی‌گیرد. متن‌های شخصی‌سازی‌شده تا زمانی که ضبط مخصوص خود را نداشته باشند از مسیر مرورگر پخش می‌شوند.
