# بایگانی ممیزی رولاوت محتوا (Content Rollout Audit Archive)

این پوشه شامل کلیه اسناد، گزارش‌های راستی‌آزمایی و عکس فوری منجمد (Frozen Snapshot) ممیزی رولاوت محتوا در فاز ۲ (آگوست ۲۰۲۶) است:
- داده‌های مسیرها: `route-audit.json`، `route-inventory.md`، `route-and-build-counts.md`
- ماتریس‌های تصمیم‌گیری و برنامه‌ریزی: `rollout-waves.md`، `page-type-matrix.md`، `priority-score-matrix.md`، `risk-and-source-gap-matrix.md`، `component-mapping.md`
- گزارش‌های تاییدیه و لاگ تغییرات: پرونده‌های `DRE-P2-*`

## وضعیت نگهداری
این اسناد و گزارش‌ها مربوط به فاز ۲ رولاوت محتوا (۶۶ مسیر Canonical اولیه) بوده، اکنون تکمیل شده‌اند و **دیگر نگهداری نمی‌شوند**. وضعیت فعلی پروژه و ناوبری با `ROUTE_REGISTRY` (که اکنون شامل ۸۳ مسیر مستقل است) توسعه یافته است. این مجموعه صرفاً جهت حفظ سابقه تاریخی (Historical Record) پروژه نگهداری می‌شود.

> **منبع حقیقت (Single Source of Truth) برای تمام مسیرها و ناوبری سایت:**
> [`src/lib/routeRegistry.ts`](../../src/lib/routeRegistry.ts)
